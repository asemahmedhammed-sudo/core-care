# Platform test matrix

Prepared: 2026-09-18. **Every test is NOT RUN.** No authenticated Salla preview URL, browser execution, test-store fixtures, or Lighthouse evidence has been recorded in this file.

This is the project's verification design, linked to the numbered official [UI / UX Review](https://docs.salla.dev/twilight-engine/uxui-review) through [requirements-ux.md](../requirements-ux.md). The chosen viewports, fixture names, operation sequences, and evidence format are implementation decisions, not extra Salla acceptance rules. Items marked for clarification must retain that status even if adjacent behavior passes.

Only a preview generated by Salla's documented development workflow is eligible here. Record the preview URL, theme commit, build timestamp, Salla CLI version, store fixture settings, browser/OS, viewport, locale, date and operator before execution. Never commit login tokens, OTP codes, customer PII, or live order details.

Suggested repeatable environment: Arabic RTL and English LTR; 390×844 and 1440×900 CSS pixels; current Chromium and Safari, followed by the browser coverage required by the technical review. These dimensions are a project test choice. Use test accounts and test-store data. Customer account deletion must use an explicitly disposable account; checkout verification stops before payment or an order with live impact.
