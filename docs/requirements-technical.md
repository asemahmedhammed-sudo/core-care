حدود مصدر الأداة: [Master Layout](https://docs.salla.dev/twilight-engine/master-layouts) يسرد كتلة `head`، بينما نسخة رائد الحالية تستخدم `head_scripts` مع `styles`, `content`, `scripts`. أُضيفت كتلة `head` مع حفظ كتل رائد وHooks؛ لا يُستنتج من ذلك تفسير إلزامي لهذا الاختلاف. [Twilight.json](https://docs.salla.dev/twilight-engine/twilight-json) يشرح `settings`, `features`, `components` وأشكال الحقول؛ مطابقة JSON للمخطط في خدمة سلة لا يثبتها تحليل JSON محلي.

تقرير الحجم الحالي بالأرقام الدقيقة في `docs/evidence/technical/size-report.json`؛ ملف القفل وأدوات البناء والأدلة توسع نطاق المشروع. الأرقام من قياس محلي محدد، **وليست حكمًا بالامتثال لحد 1MB**. أي إعادة بناء تُحدّث التقرير وتاريخه.
