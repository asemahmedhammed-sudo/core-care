# ثيم Twilight للعناية والجمال — نسخة تطوير

مشروع ثيم فعلي مبني على [رائد الرسمي](https://github.com/SallaApp/theme-raed) لمنصة سلة Twilight، وليس صفحة HTML مستقلة. تاريخ التحقق من الوثائق والأساس: **2026-09-18**. المعاينة على متجر سلة الرسمي **لم تُنفذ** بعد، ولذلك الثيم **غير جاهز للتقديم للمراجعة** ولا يُدّعى قبوله من سلة.

## ما أُنجز

- بنية `src/views` و`twilight.json` وWebpack وSalla Watcher الرسمية موروثة من رائد `1.358.0` عند SHA موثق في `docs/evidence/PROJECT_AUDIT.json`.
- مكونات قابلة للتحرير: بانر نص/صورة منفصل، مجموعات تصويرية بتخطيطين، تبويبات روتين العناية بمنتجات يختارها التاجر. تستخدم جميع روابط المحتوى حقول Salla المدعومة، وتستخدم بيانات المنتجات من سلة.
- هوية كريمية/زيتونية/ذهبية مع لوحة وردية أو لون المتجر، مطبقة على الترويسة، بطاقات المنتج، الفئات، القوائم، المنتج، التصنيف والتذييل. الملفات في `src/assets/styles/06-beauty/`.
- الحفاظ على صفحة المنتج والسلة والبحث والعميل والمدونة والعلامات والتكاملات الموروثة من رائد، مع تعديلات أمان وترجمة مذكورة في CHANGELOG.

## البناء والتحقق المحلي

يتطلب المشروع Node متوافقًا مع `package.json` وpnpm وفق ملف القفل:

```sh
pnpm install --frozen-lockfile
./node_modules/.bin/webpack --mode production
node scripts/audit-theme.mjs
node scripts/measure-theme.mjs
```

البناء المحلي ينشئ `public/` ولا يثبت توافق الثيم مع سلة. `pnpm build` قد يحاول فحص/إعادة تثبيت الحزم وفق إعدادات pnpm في البيئة؛ أمر Webpack المباشر استُخدم هنا لتجنب تغيير ملف القفل أثناء التحقق. استُخدم CLI سلة المستقر `3.2.56` للتحقق من أمر المساعدة؛ `salla theme preview` يحتاج تسجيل الدخول وربط مستودع ومتجر تجريبي، ولم يُشغّل لغيابها. بعد الربط استخدم [معاينة سلة الرسمية](https://docs.salla.dev/421878m0)، ثم سجّل الرابط والنتائج في `docs/tests/`.
